# Compacted

A 2D factory game about automating inside tight space: every dimension is a small grid, and dimension controllers fold more space into a single tile.

| Folder | What's in it |
|---|---|
| `docs/` | Requirements (`requirements.md`) and early-game content (`early-game.md`) |
| `prototype/` | Web prototype for testing rules quickly (see its README) |
| `Unity/Compacted/` | The production Unity project (Unity 6.3, URP 2D, UI Toolkit) |

Binary art and audio are stored with Git LFS (see `.gitattributes`).

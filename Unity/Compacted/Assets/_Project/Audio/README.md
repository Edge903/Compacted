# Audio

Drop sound files here. Unity imports them automatically.

| Folder | For |
|---|---|
| `SFX/` | World sounds: placing, destroying, machines working, items moving, fluids |
| `UI/` | Interface sounds: clicks, opening windows, tech completed, errors |
| `Music/` | Music tracks |
| `Ambience/` | Background loops |

- **Formats:** `.wav` or `.ogg` preferred (`.mp3` works too). Audio files are stored with Git LFS.
- **Names:** lowercase with underscores, ideally saying what triggers them, e.g. `place_block.wav`, `machine_furnace_loop.ogg`, `ui_click.wav`.
